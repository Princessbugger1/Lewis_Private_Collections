# Compact Status Controls

COA status should use a compact tap-to-cycle control rather than a large form box. It retains the three-state behavior: ❓ Unknown / Not Checked → ✅ Yes → ❌ No → ❓.

The same compact treatment should be used for other simple yes/no/unknown status fields where appropriate, while preserving clear labels and accessibility on phone and desktop.

Changing the visual size must not change the stored value or its meaning.
