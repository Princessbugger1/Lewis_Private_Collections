# Lewis Private Collections — Help & Troubleshooting

This document defines the user-help area to be integrated into the catalog without changing or deleting collection data.

## Help
- Getting Started
- Adding and editing an item
- Adding photos
- Slab/certification lookup
- Research without leaving the catalog
- Backups and restore
- Phone/Desktop view
- Settings and optional fields

## Troubleshooting
- Catalog will not open
- An item is missing from the list
- A photo or import did not work
- Certification lookup did not find a result
- A field is hidden because its setting is off
- Restore a previous backup
- Contact Support

## Support report
The future in-app support form should let the user describe the problem and optionally attach a screenshot. It should avoid exposing collection contents or other private information unless the user explicitly chooses to send it.

## Design rule
Help and Troubleshooting must be easy to find and must not replace or hide the main catalog. Errors should explain what happened and give the user a safe next step.
