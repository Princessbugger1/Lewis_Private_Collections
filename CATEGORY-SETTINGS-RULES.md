# Category Visibility Settings

Category visibility is an independent display preference.

The user can turn entire categories on or off in Settings, including Paper Money, Tokens, Counterfeit, Commemorative, Medals, and any future/custom classification.

Turning a category OFF:
- hides its category section/filter/entry option where appropriate;
- does not delete, archive, modify, or export-delete any records;
- does not prevent existing records from being restored by turning the category back ON;
- must preserve all photos, notes, certification, values, research, and other fields.

Turning a category ON restores its visibility.

Settings should be accessible from the catalog's primary Settings control and should not require navigating to a hidden or obscure screen.

If a hidden category has existing records, the Settings UI should make clear that records still exist and are simply hidden from the current display.

Custom classifications must receive the same visibility behavior as built-in classifications.
