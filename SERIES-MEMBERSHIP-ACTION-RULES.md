# Series Membership Action Rules

Series membership actions must be clearly separated from record deletion.

- **Remove from Series** removes only the selected series membership; the collection record remains intact.
- **Change Series** allows the user to select another existing series or create a new one without deleting the record.
- If an item has no series after removal, it remains accessible through its classification, country/issuer, search, and other applicable views.
- Removing an item from a series must not remove its photos, notes, grade, certification information, or other record fields.
- **Delete Coin/Item** is a separate record-level action and must never be triggered by Remove from Series.
- Record deletion follows the established Recently Deleted/Trash and recovery workflow.
- Remove-from-series controls should be placed near series membership/edit controls, while Delete should be visually and functionally separated.
- Confirmation language must explicitly name the action so the user can tell whether they are removing a grouping or deleting the record.
