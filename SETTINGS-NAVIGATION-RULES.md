# Settings Navigation Rules

Settings must be a first-class, easy-to-find part of the catalog interface.

- Settings should have its own clearly labeled button/tab in the primary navigation rather than appearing only as a large card on a home screen.
- On phones, the Settings control must remain visible or reachable from an obvious, consistently placed navigation control.
- On desktop, Settings should be available from the primary navigation without requiring the user to search through collection categories.
- The phone/desktop display preference must not hide Settings or other core catalog capabilities.
- Settings should be organized into understandable sections instead of one long undifferentiated page.
- Changes to settings should affect presentation/preferences unless a setting explicitly states that it changes catalog data.
- Settings changes must not delete or duplicate collection records.
- Destructive or security-sensitive settings require explicit confirmation.
