# Mobile and Desktop Responsive Rules

The catalog must work well on a phone and on a desktop without hiding important controls.

- Mobile is a first-class experience, not a reduced desktop page.
- Desktop may use wider layouts, while phone layouts use compact navigation and appropriately sized controls.
- The user must always be able to find Settings, Search, Add Item, and the current collection/category navigation.
- Any desktop/mobile mode switch must be obvious and easy to find rather than buried in an obscure menu.
- If the browser's desktop-site mode is used, the app must not depend on a hidden in-app toggle to recover a usable phone layout.
- Controls should be large enough for reliable tapping but not oversized cards that waste screen space.
- Compact three-state controls must remain readable and tappable on small screens.
- Tables and dense catalog information should adapt to narrow screens without silently dropping important fields.
- Photos should scale appropriately and remain usable for coin and slab review.
- Responsive changes must affect presentation, not collection data.
