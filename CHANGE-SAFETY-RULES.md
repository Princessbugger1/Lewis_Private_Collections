# Change Safety Rules

- Every saved item remains editable after creation.
- Classification/type is editable for every item and every future category.
- Changing one field changes only the selected record.
- Country/issuer changes automatically affect country grouping without moving/copying the record.
- Hidden categories are a display preference only; their records remain intact.
- Delete is an explicit user action and must not be triggered by editing or reclassification.
- External scan/research results are proposals until the user reviews and saves them.
- Unknown values remain explicitly unknown rather than being guessed.
- New features must preserve existing records and stored data.
