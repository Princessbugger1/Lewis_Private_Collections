# Phone/Desktop Requirements

The next live UI change must make the display choice obvious and persistent.

- Show **📱 Phone** and **🖥️ Desktop** controls in an easy-to-find location.
- Keep the controls visible on a phone; do not bury them in Settings.
- Persist the selected display mode locally on the device.
- Switching display mode must not modify, hide, or delete collection records.
- Keep the existing responsive layout as the fallback when no preference has been chosen.
