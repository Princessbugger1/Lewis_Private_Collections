# Editable Classifications

Every collection item classification is editable after creation. This applies to coins, paper money, tokens, medals/other numismatic items, and any future classification added to the catalog.

A classification is metadata on the individual record, not a permanent type lock. Users can change a record from one classification to another later and save it.

Changing classification must not delete the record, images, notes, research history, certification information, or other fields. The record remains the same item; only its classification changes.

The catalog must not assume that only the currently known categories (such as Counterfeit, Commemorative, Token, or Paper Money) are editable. The edit mechanism applies to the complete classification set and future classifications.

If classifications are hidden in Settings, hiding changes visibility only. It must never delete or modify records.
