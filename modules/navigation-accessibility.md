# Navigation Accessibility Checklist

- Navigation uses a semantic `nav` landmark.
- Every destination is a real button and can receive keyboard focus.
- The active destination is exposed with `aria-current="page"`.
- Labels remain readable at narrow phone widths.
- Navigation must not depend on color alone to communicate state.
- The integration must preserve normal browser back/forward behavior where applicable.
- The navigation layer must not capture focus or prevent normal scrolling outside its controls.
