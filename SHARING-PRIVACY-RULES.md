# Sharing and Privacy Rules

The catalog is private by default. Sharing is an explicit action and must expose only the information the user chooses to share.

- Viewing, cataloging, researching, backing up, and sharing are separate operations.
- A normal collection record is never automatically published because it was saved or researched.
- Shared views should use a read-only projection rather than exposing the editable underlying record.
- Precise home address, storage location, private notes, acquisition cost, security/access information, and other sensitive fields must remain excluded from shared views by default.
- The user should be able to choose which non-sensitive fields are included in a shared view.
- Share links should use non-predictable identifiers and be revocable.
- Where sharing infrastructure supports it, optional expiration, access codes, and rate limiting should be available.
- Revoking a share must not delete or modify the underlying collection record.
- Exporting a record is not the same as publishing it.
- Outside research services must not receive collection or location information merely because a share or research feature exists.
- Privacy controls should be understandable on both phone and desktop and should not be buried behind obscure navigation.
