# Series Search and Sorting Rules

Series must be first-class searchable/filterable metadata, not merely a visual heading.

- Search by full or partial series name.
- Search results remain available even when a series is hidden in Settings.
- Sort a series by year/date, mint mark, denomination, catalog number, or other applicable fields.
- Default sort for dated U.S. series is chronological ascending unless the user selects another sort.
- Preserve stable item records when filtering or sorting; these are views only.
- A custom series participates in search and sorting exactly like a built-in series.
- Search must not expose private fields that the user has marked private in any shared/read-only view.
