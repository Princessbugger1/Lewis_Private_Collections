# Coin Entry Workflow

The first-entry workflow should be fast for ordinary coins while preserving review and editing for unusual items.

1. Start a new item.
2. Choose or confirm the classification (Coin, Ancient, Token, Counterfeit, Commemorative, Paper Money/Banknote, etc.).
3. Capture/import photos when available.
4. Enter or scan basic identification information.
5. Use automatic identification/research only as an optional assistive step.
6. Present suggested country/issuer, series, denomination, date, mint, variety, certification, and other fields for review.
7. Allow Accept, Change, Reject, or Needs Review without overwriting user-entered data.
8. Save the stable item record.
9. Automatically make the item available in applicable country/issuer, classification, and series groups without creating duplicates.
10. Allow the user to add/edit custom series or classifications later.

## Important safety behavior

- Manual entry always remains possible.
- A missing research result never prevents saving.
- Suggestions never silently replace confirmed user data.
- Country/issuer and classification can be corrected later.
- Saving does not publish or share the item.
- Private fields remain private unless explicitly shared.
