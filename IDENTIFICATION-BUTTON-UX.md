# Identification Suggestion Button UX

Automatic suggestions use compact, medium-sized controls that are easy to see and tap on a phone without becoming large card-like boxes.

Preferred layout:

Suggested: Mercury Dime
[ ✓ Accept ] [ ✎ Change ] [ × Reject ]

Controls must:
- remain comfortably tappable on touch screens;
- use short labels and/or familiar icons;
- have sufficient spacing to prevent accidental taps;
- remain readable at normal phone text size;
- collapse gracefully on narrow screens without becoming microscopic;
- never hide the underlying editable field.

After Accept, the suggestion becomes the user's confirmed value. Change opens the normal editor/selector. Reject dismisses that suggestion without deleting the item or its existing metadata. If confidence is insufficient, show Needs Review rather than forcing a choice.
