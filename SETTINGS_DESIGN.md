# Lewis Private Collections — Display Settings

The catalog should support a simple Settings control that hides or shows optional fields without deleting their saved data.

## Default display
- Country
- Type
- Denomination
- Year
- Mint
- Series / type suggestion
- Grade
- Variety / VAM
- Purchase price
- Estimated value
- Collection / Set
- Location
- Notes
- Certification

## Optional advanced display
These should be OFF by default and can be enabled when wanted:
- Weight / standard weight / actual weight
- Composition
- Diameter / thickness / edge
- Metal testing (including Sigma test information)
- Detailed provenance
- Specialist research links

## Rules
1. Turning a field OFF hides it; it never deletes the stored information.
2. Turning it back ON restores the field and its saved values.
3. Settings are personal to the catalog/device.
4. A clear Settings button should remain visible near the Phone/Desktop controls.
5. Include a “Restore default display” option.
6. Keep Simple View, Standard View, and Advanced View possible later without changing the underlying collection data.
7. Settings must not change or erase existing coin records.
