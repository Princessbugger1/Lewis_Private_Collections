# Photo Display Rules

## Owner photographs are the primary record
Every collectible can store the owner's original photographs. The catalog may automatically create smaller thumbnails from those same photographs for compact lists, search results, and cards.

### Coins
- Obverse: owner photo
- Reverse: owner photo
- Edge: optional owner photo

### Paper Money
- Face/front: owner photo
- Reverse/back: owner photo

## Thumbnail behavior
A thumbnail is a smaller presentation of the owner's actual photograph. Tapping it opens the larger owner photograph. No separate duplicate reference photo is required for this purpose.

## External reference images
External images are optional and are never treated as photographs of the owner's item. They must have a clear, unobtrusive Reference Image label and should retain source/credit information where available.

## Privacy rule
The interface should make it visually clear which images belong to the owner's collection and which are research references.
