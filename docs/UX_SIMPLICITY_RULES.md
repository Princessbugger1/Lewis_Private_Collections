# UX Simplicity Rules

The catalog should expose powerful features without making ordinary coin entry complicated.

- Keep the primary coin-entry screen focused on common fields.
- Put optional/advanced fields behind Settings or an expandable Details area.
- Use plain-language labels and short help text.
- Preserve one-tap access to the most common actions.
- Avoid forcing collectors to configure the catalog before they can add a coin.
- Hide unused optional features without deleting their data.
- Keep destructive actions visually and logically separated from normal editing.
- Prefer progressive disclosure: simple by default, powerful when needed.

These rules apply to future UI work across the catalog.
