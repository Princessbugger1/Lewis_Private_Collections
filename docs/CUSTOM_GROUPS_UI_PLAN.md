# Custom Groups UI Plan

## Collector workflow
1. Open Groups.
2. Tap **+ New Group**.
3. Enter any name.
4. Select one or more coins.
5. Tap **Add to Group**.
6. Filter the collection by that group when needed.

## Management
- Rename a group without changing coin records.
- Remove selected coins from a group without deleting them.
- Delete a group without deleting its coins.
- Support multi-select so large collections can be organized quickly.

## Safety
Group membership is independent from active/sold/transferred/trash status. A grouping operation must never move a coin into Trash or permanently delete it.
