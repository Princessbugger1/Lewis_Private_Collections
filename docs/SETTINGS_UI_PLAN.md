# Settings UI Plan

Settings should be simple and collector-friendly.

## Sections
- Display & Layout
- Coin Details
- Organization
- Research & Tools
- Data & Backup
- Help & Troubleshooting

## Optional feature controls
Each optional catalog feature has a clear On/Off control. Turning a feature off changes visibility only; stored collection data remains intact.

## Safety
- Destructive actions are kept in Data & Backup, not mixed with ordinary display settings.
- Resetting settings must not delete coin records.
- Data deletion and Empty Trash require separate confirmation.
- Settings should include an easy way to restore recommended defaults.
