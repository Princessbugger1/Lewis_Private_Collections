# Export Profile UI

## Goal
Make sharing a selected set or the entire collection simple enough for a phone user.

## Flow
1. Tap Export / Share.
2. Choose scope: This coin, Selected coins, Group, Filtered results, or Entire catalog.
3. Choose profile: Sale List, Printable List, Spreadsheet, or Full Export.
4. Review included fields.
5. Create the separate export.
6. Use the phone's normal share action to send the file.

## Safety defaults
- Sale List excludes private purchase cost, storage location, and private notes by default.
- Full Export is clearly labeled as containing more information.
- The master catalog is never edited by creating an export.
- The recipient receives a copy, not editing access to the live catalog.

## Convenience
Remember the user's last export profile as a convenience, but always show a final review before creating a shareable export.
