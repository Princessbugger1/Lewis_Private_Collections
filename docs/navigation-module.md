# Navigation Module

## Purpose
Provide a phone-first navigation layer for the Lewis Private Collections catalog without replacing the existing main catalog file.

## Primary destinations
1. Coins
2. Paper Money
3. Lookup
4. Collection
5. Settings

## Rules
- Keep navigation compact and thumb-friendly.
- Clearly indicate the active destination.
- Preserve all existing collection data.
- Global settings remain separate from per-record optional sections.
- Per-record options such as COA, Photos, Composition, and History remain available when enabled for an individual record.
- Navigation must not require changes to existing records merely to display the navigation.

## Integration strategy
This module is intended to be integrated into the existing app shell after it is reviewed. It should not replace `index.html` wholesale.
