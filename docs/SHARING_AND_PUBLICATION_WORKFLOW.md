# Sharing and Publication Workflow

## Goal
Prevent accidental publication of private collection information while allowing the owner to intentionally share selected records when desired.

## Default
A collection record is private unless the owner explicitly chooses to share it.

## Sharing levels
A future sharing system may support:
- Private — visible only in the owner's collection
- Selected — only specifically chosen fields/media are shared
- Public — the owner intentionally publishes the selected record

## Before sharing
The app should show a clear preview of what will be shared, including fields, photographs, reference material, and any identifying or financial information.

## Sensitive information
Purchase price, estimated value, storage location, private notes, personal information, and other sensitive fields should be excluded from public sharing unless the owner deliberately includes them.

## Media
Owner photographs and external reference images must remain distinguishable in a shared record. Reference source/credit information should be retained when appropriate.

## Reversibility
Where the hosting platform permits it, the owner should be able to stop sharing a previously published record. The interface should not imply that withdrawing a page can erase copies already saved elsewhere on the internet.

## Safety rule
Never publish collection records merely because the application itself is hosted on a public web address.
