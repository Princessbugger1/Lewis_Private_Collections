# Coin Detail View Layout Specification

## Goal
Show complete information without making the main list cluttered.

## Behavior
- The main list remains compact.
- Tapping a coin opens a dedicated Detail View.
- The Detail View shows the full record and photos.
- Optional fields such as weight and composition can be shown or hidden through settings, but the Detail View remains the place to see the complete available record.
- The user can return to the list without losing the prior search/filter position.

## Layout
Present information in clear sections rather than one long wall of fields:
1. Identification
2. Mint / Date / Denomination
3. Physical details (weight, composition, measurements)
4. Grading / certification
5. Provenance / purchase information
6. Testing and verification
7. Photos
8. Notes

## Editing
An obvious Edit control is available from the Detail View. Editing is separate from simply viewing a record to reduce accidental changes.

## Mobile design
Use readable labels, generous tap targets, and collapsible sections where helpful. Avoid showing every optional field on the main list.
