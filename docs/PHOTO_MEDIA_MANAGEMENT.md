# Photo and Media Management

## Goal
Keep the owner's collectible photographs organized, identifiable, and recoverable as the collection grows.

## Owner media
Each owner photograph should be associated with a stable record ID and a clear role, such as:
- Coin obverse
- Coin reverse
- Coin edge
- Paper-money face/front
- Paper-money reverse/back
- Additional detail

## Original preservation
The original owner photograph should remain recoverable even when the interface creates thumbnails or optimized display copies.

## Thumbnails
Thumbnails are display derivatives, not replacements for the original photograph. A tap should open the appropriate full-size/available original-quality image.

## File relationships
Moving, renaming, or replacing a display thumbnail must not break the connection to the master record or original media.

## Reference separation
External reference images remain separate from owner media at every stage: storage, display, export, and sharing.

## Missing media
If a photograph is unavailable, the record should indicate that clearly rather than displaying an unrelated image or a reference image in its place.

## Backup
Collection exports should preserve media references and relationships. A future complete backup workflow should provide a way to include the actual owner media, not merely the catalog text.

## Future-proofing
Media metadata should remain structured so additional photo types, scans, certificates, or other attachments can be added without changing the identity of the collectible.
