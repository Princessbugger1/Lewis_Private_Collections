# Export & Share Specification

The catalog must allow a collector to create a separate, read-only-friendly export without giving another person access to the live collection.

## Selection options
- One coin
- Multiple selected coins
- A custom group/collection
- Current filtered results
- Entire catalog

## Export profiles
- Sale List
- Printable List
- Spreadsheet/CSV
- Full Catalog Export

## Field selection
Before export, the user can choose which fields are included. Private fields such as purchase cost, storage location, private notes, or testing details should not be included unless explicitly selected.

## Safety
- Exporting never grants access to the live catalog.
- The exported copy must not contain controls that can modify the master catalog.
- The master catalog remains unchanged by sharing/exporting.
- Clearly label exports with their creation date and an indication that they are a separate copy.

## Bulk sharing
The user can select all records and export them together in one operation. Large collections should use the same selection and field rules without requiring the user to repeat the process for every coin.
