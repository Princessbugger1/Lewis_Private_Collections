# Collection Valuation Policy

## Goal
Keep valuation useful without presenting an estimate as a guaranteed market price.

## Separate valuation types
Where practical, the catalog should distinguish:
- Owner purchase price
- Owner cost basis/total cost
- Research estimate
- Recent comparable sale information
- Insurance/reference value
- Actual realized sale price

These values should not be silently substituted for one another.

## Date matters
Every research-based valuation should retain the date it was obtained. Market values can change over time.

## Source and condition
A valuation result should identify its source when practical and should account for condition/grade, certification, variety, authenticity, and other relevant factors when those are known.

## User control
The owner can enter or correct valuation information. Research suggestions remain unconfirmed until accepted.

## No guaranteed value
The catalog should clearly distinguish an estimate from an actual offer, auction result, or completed sale. It should never imply that a collectible is worth a specific amount merely because a research service produced an estimate.

## Privacy
Purchase prices, values, and related financial information are private collection data unless the owner intentionally includes them in a sharing/export operation.

## Future-proofing
Valuation fields should remain structured so multiple sources and dated observations can be retained without overwriting the historical record.
