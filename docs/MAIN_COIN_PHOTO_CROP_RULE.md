# Main Coin Photo Crop Rule

The first/main coin photo is the catalog image.

- Cropping is optional.
- If cropped, the cropped result becomes the main catalog image and thumbnail.
- Do not create a separate full-size thumbnail copy.
- Keep the workflow simple: add photo → crop if needed → done.
- Reverse and Edge photos remain separate and are not forced through the main-photo crop workflow.
- Storage optimization should happen automatically without presenting technical image-storage choices to the collector.
