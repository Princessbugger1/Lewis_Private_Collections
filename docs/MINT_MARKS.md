# U.S. Mint Mark Reference

The master catalog should support historical and current U.S. mint marks without forcing every record to use one.

## Required marks
- P — Philadelphia
- D — Denver
- S — San Francisco
- C — Charlotte
- CC — Carson City

## Additional marks to support
- O — New Orleans
- W — West Point
- Other historical marks as applicable
- No mint mark where the issue calls for none

## Data rule
Store the mint mark as structured record data, not only inside free-text notes, so users can search and filter by it.

## Display rule
Use the familiar mint-mark abbreviation in compact views while allowing the full mint name to appear in the item details.
