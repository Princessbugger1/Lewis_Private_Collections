# Advanced Search Examples

## Goal
Make the catalog flexible enough to answer practical collection questions with simple searches and combined filters.

## Examples
The owner should be able to search for:
- all silver coins
- all copper coins
- all gold coins
- all Morgan dollars
- all coins from a particular country
- all items from a date range
- all certified items
- all items with COA = Yes
- all items with COA = No
- all items with COA = Unknown / Not Checked
- all items missing photographs
- all items that need research
- all items with a particular certification number
- all paper money with a particular serial number

## Combined searches
Multiple conditions should work together, for example:
- silver + U.S. + dollar
- copper + Lincoln cent + date range
- gold + certified + particular grading service
- paper money + denomination + series + date
- silver + COA = Yes + photographs complete

## Natural search
The interface should support simple wording where practical, while structured filters remain available for precise results.

## Saved searches
The owner may later be able to save useful searches for repeated use, such as a silver inventory or items needing research.

## No destructive behavior
Searching and filtering must never edit, delete, merge, or otherwise modify collection records.
