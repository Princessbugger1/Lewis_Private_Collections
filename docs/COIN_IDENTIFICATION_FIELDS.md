# Coin Identification Fields

## Goal
Keep the core coin record useful for identification without making every optional detail mandatory.

## Core fields
The main record should support the primary identifying information needed to recognize and catalog a coin, including denomination, date, mint/mark where applicable, country or issuing authority, and variety information where applicable.

## Composition
Composition is a searchable structured field and can be used to find groups such as Silver, Copper, Gold, and other recorded materials.

## Variety
Variety information should remain available as a dedicated field or optional section, with its applicable checked status using the standard three-state system when appropriate.

## Optional grading and testing
Grading, certification, metal testing, and other specialized information should not be required to create a basic record and may be independently hidden through Settings.

## Unknown values
If an identifying field has not been checked or is not known, it should remain explicitly unknown rather than being filled with an assumed value.

## Mobile entry
Core identification fields should be quick to enter on a phone, with additional details kept in optional sections.
