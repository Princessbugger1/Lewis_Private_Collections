# All Coin Photos Can Be Cropped

In the Edit section, Obverse / Face, Reverse, and Edge photos all use the same photo-editing behavior.

- Tap a photo to inspect it larger.
- Zoom and drag while inspecting.
- Choose the explicit Crop action to change that photo.
- Confirming a crop replaces only that photo's stored image.
- Cancel leaves the existing image unchanged.
- Each photo remains independent.
- No separate thumbnail copy is created.
- Normal viewing remains inspection-only and never changes a saved image.

This removes unnecessary special-case rules: if a collector is editing a coin photo, that photo can be cropped.
