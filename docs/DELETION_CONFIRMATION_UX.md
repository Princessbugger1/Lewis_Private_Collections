# Deletion Confirmation UX

## Goal
Make destructive actions understandable without making normal catalog use annoying.

## Archive
Archiving is low-risk and should use a simple confirmation for bulk actions when appropriate.

## Move to Trash
Before moving records to Trash, show the selected count and explain that the records remain recoverable for the configured Trash retention period.

## Permanent Delete
Permanent deletion requires a stronger confirmation than moving to Trash. Clearly state that the record will no longer be recoverable through the app.

## Photo cleanup
When removing old photo copies after a verified backup, describe the files being removed and the storage location. Do not label this as deleting the coin record.

## Bulk operations
For large selections, show a review step with the number of records and the type of action. Avoid vague buttons such as "OK" for destructive actions; use specific labels such as "Move 25 Coins to Trash" or "Permanently Delete 25 Coins."

## Accidental taps
Destructive controls should not be adjacent to common editing/navigation controls without adequate separation. Where practical, provide an immediate undo for non-permanent actions.

## Accessibility
Confirmation text and action labels should remain understandable on phone and desktop layouts, with adequate touch targets and keyboard focus behavior.
