# Help & Troubleshooting

The catalog should include a simple Help area so a collector can solve common problems without leaving the app.

## Help entry points
- Settings → Help & Troubleshooting
- Contextual help from important screens when useful
- Clear links/buttons for common recovery actions

## Topics
- Adding and editing a coin
- Opening the full coin details
- Search, filters, and custom groups
- Photos and camera permissions
- Backup/import/export and data recovery
- Trash, restore, and Empty Trash
- Settings and hidden optional fields
- Installation/PWA/offline behavior
- What to do if a value or field is missing

## Troubleshooting style
Use short, plain-language steps. Prefer “Try this” instructions over technical terminology. Explain what is safe to change and warn clearly before destructive actions.

## Contact/support
Provide a simple support/contact area that can be configured later. Do not hard-code an unverified email address or promise a support service that does not exist.

## Recovery principle
Help must never instruct a user to delete collection data as a first troubleshooting step. Backup/recovery options should be presented before destructive resets.
