# Image Crop UX

## Coin photo flow
When adding a coin photo, offer an optional editing step:

1. Add or capture the photo.
2. Crop around the coin if desired.
3. Rotate if needed.
4. Confirm the crop or skip editing.
5. Generate the appropriate catalog thumbnail/derived image.

## Original protection
The original master photo remains untouched by cropping. Users can return to the original and create a different crop later.

## Crop controls
- Touch-friendly on phones and tablets.
- Mouse and keyboard friendly on computers.
- Zoom while positioning the crop.
- Rotate in predictable increments.
- Provide Cancel/Skip without changing the original.
- Provide Reset Crop when editing an existing derived crop.

## Profile photo
Use the same editor for profile/avatar images, but default to an appropriately small output size so profile images do not consume unnecessary storage.

## Storage behavior
Cropping should normally produce a display-sized derivative rather than a second full-resolution master. Repeated crop edits replace obsolete derivatives when safe.
