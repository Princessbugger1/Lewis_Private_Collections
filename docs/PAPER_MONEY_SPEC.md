# Paper Money Catalog Specification

## Scope
Paper money is a first-class collection category alongside coins, commemoratives, medals, tokens, and other collectibles.

## Record type
A paper-money record can include:
- Country / issuing authority
- Denomination
- Year or date
- Series
- Note type
- Fr / catalog number when applicable
- Serial number (optional and private by default)
- Signatures / varieties
- Grade and grading service
- Certification number
- Condition notes
- Front and back photos
- Purchase/source information
- Value and other user-defined fields

## Organization
Paper money should have its own appropriate organization and filters rather than being forced into coin-specific fields such as mint mark.

## Search
The main search can find paper-money records alongside other collection records, while a Category/Type filter can restrict results to Paper Money.

## Privacy
Serial numbers and other potentially sensitive note details should never be included in a share/export by default unless the user explicitly selects them.
