# Individual Optional Sections

## Rule
A global Settings switch controls whether an optional section is normally shown, but it must not prevent the owner from using that section for one specific item.

## Individual access
If a section is OFF globally, the individual item editor should offer a simple action such as **Add COA**, **Add Photos**, **Add Composition**, or **Add History** when applicable.

Tapping that action reveals the fields for that item only. It does not turn the section ON for the entire catalog.

## Examples
- COA OFF globally → a particular coin can still use **Add COA**.
- Photos OFF globally → a particular coin can still use **Add Photos**.
- Composition OFF globally → a particular coin can still use **Add Composition**.
- History & Provenance OFF globally → a particular coin can still use **Add History**.

## Saving
Information entered through an individual optional section is saved with that item and remains available even if the global setting is later turned OFF.

## Editing
When an item already contains an individually enabled section, opening that item should show its saved section so it can be edited.

## Clean interface
The individual actions should be small and simple so the main phone screen does not become cluttered.

## Priority
This behavior is preferred over requiring the owner to visit Settings every time a single collectible needs an optional detail.
