# Collection Owner Profile

## Purpose
Provide an optional personal identity area for the owner of a collection without turning the catalog into a social-media feature.

## Profile
- Optional display name / collection name
- Optional profile/avatar picture
- Default neutral avatar when no picture is provided
- Change or remove the picture at any time

## Privacy
The profile picture and display name are local catalog profile information. They should not be included in exports by default.

## Export option
For printable or shareable catalogs, the user may explicitly choose to include the owner name and/or avatar in the export.

## UX
Keep the profile area compact and unobtrusive. It should identify the collection owner without taking attention away from the coin catalog.
