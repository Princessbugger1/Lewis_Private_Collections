# Image and Reference Photo Specification

## Collection photos
Each record supports owner photographs as the primary images.

### Coins
- Obverse (front)
- Reverse (back)
- Edge (optional, recommended when edge details matter)

### Paper Money
- Face (front)
- Reverse (back)

## Reference images
When an identification or research feature uses an image that is not the owner's photograph, it must be clearly marked as a **Reference Image** or **Reference Photo** with a small, unobtrusive credit/source note where applicable.

Reference images must never be presented in a way that suggests they are photographs of the owner's actual item.

## User experience
- Owner photos should be visually distinguished from reference images without cluttering the record.
- Reference/source information should be available when the user taps or opens the image details.
- Buyer-facing exports should clearly distinguish the owner's photographs from any reference images and should avoid implying that a reference image depicts the item being offered.
