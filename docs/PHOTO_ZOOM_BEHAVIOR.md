# Coin Photo Zoom Behavior

## Crop mode
When cropping the main coin photo, zooming is an editing aid only. It lets the collector enlarge the coin visually, position it accurately inside the crop area, and remove excess background. The zoom level itself is not saved as a separate image setting.

## Viewing mode
When viewing a saved coin, tapping the main thumbnail/photo opens the larger photo view. The collector can zoom and pan to inspect details. Closing the viewer returns to the coin record without changing the stored image.

## Simplicity
Use the same familiar touch gestures where possible: pinch to zoom and drag to reposition. On computers, mouse-wheel/trackpad zoom and drag should work, with accessible controls available as an alternative.

## Storage
Viewing and crop-mode zoom do not create additional image files. Only the confirmed main catalog image is stored according to the main coin photo storage policy.
