# Reference Image and Source Credits

## Owner photographs
Photographs taken by the owner are treated as collection media and are not labeled as external references.

## External reference images
When a research result uses an image that is not the owner's photograph, the interface must clearly identify it as a **Reference Image**. The label should be small and unobtrusive while still being readable.

## Tap-to-enlarge behavior
A reference thumbnail may be shown beside research results. Tapping it should open the larger reference image and associated source/credit information when available.

## Separation rule
A reference image must never replace, overwrite, or be stored as an owner photograph for the collectible.

## Source information
Where practical, retain the source, attribution, and relevant usage information associated with an external reference image. The catalog should not imply ownership of third-party images.

## Future-proofing
Reference images should be stored as research assets/links separate from the master owner-media fields so a future simplified catalog can omit them without affecting the owner's photographs.
