# Provenance and Ownership Records

## Goal
Give each collectible a place to record where it came from and how the owner acquired it without forcing provenance information when none is known.

## Provenance fields
Where applicable, a record may include:
- source/person or organization
- acquisition date
- acquisition method
- purchase location or event
- prior owner information supplied by the owner
- supporting documentation
- provenance notes

## Unknown information
Unknown or unavailable provenance must remain distinct from a negative statement. The catalog should allow "Unknown / Not Checked" rather than requiring a guess.

## Documents and media
Receipts, certificates, auction records, and other supporting documents may be attached to the collectible as owner-controlled media. External reference documents remain separate from owner documents.

## Privacy
Provenance can contain names, addresses, transaction details, or other private information. It is private collection data by default and should not appear in a public/shared record unless the owner deliberately includes it.

## Verification
Provenance supplied by a research source or prior owner should not automatically be presented as independently verified. The owner can mark important provenance information as confirmed, corrected, or needing more information.

## Future-proofing
Provenance records should remain attached to the stable collectible record ID so descriptive changes do not break the history of the item.
