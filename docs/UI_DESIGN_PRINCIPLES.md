# UI Design Principles

## Goal
Keep the catalog powerful without making the main screens feel crowded.

## Main screen priorities
Show the information most useful for identifying and managing an item first. Advanced research, provenance, valuation, and technical details can be available through secondary sections or expandable areas.

## Compact controls
Use compact controls for repeated fields, including the three-state applicable fields. Controls should be understandable without requiring a separate help screen.

## Photo thumbnails
The owner's actual item photo should be the primary thumbnail. A thumbnail should remain small enough to keep lists clean while opening the full photo when tapped.

## Reference thumbnails
External reference images use a small, unobtrusive reference label. Tapping the thumbnail opens the larger reference image and source information when available.

## Progressive disclosure
Do not place every possible field on the main record screen. Group related details so users can reveal additional information when needed.

## Accessibility
Interactive controls should have readable labels, adequate touch targets, and meaningful text alternatives. Color or icons should not be the only way a state is communicated.

## Responsive design
The catalog should work well on a phone first while remaining usable on larger screens. Layout should adapt rather than requiring a separate mobile database.

## Future basic version
A basic view can hide advanced sections while retaining access to the same master records and photographs.
