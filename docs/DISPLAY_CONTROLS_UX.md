# Display Controls UX

## User-facing controls
The appearance setting should be easy to find without making the main catalog cluttered.

Recommended options:
- **Light**
- **Dark / Blackout**
- **Use Device Setting**

## Device behavior
The catalog should work on phones, tablets, laptops, and desktop computers. On touch devices, controls must be tap-friendly. On desktop, controls must also support mouse and keyboard interaction.

## Persistence
Remember the user's chosen appearance where preferences are available. If **Use Device Setting** is selected, respond to operating-system theme changes without requiring an app restart when technically supported.

## Accessibility
Do not use color alone to communicate state. Maintain readable contrast, visible focus indicators, and sufficient touch targets in both themes.

## Professional presentation
Dark mode should look intentionally designed rather than simply blackening the existing interface. Coin photos and certification details should remain easy to inspect in either theme.
