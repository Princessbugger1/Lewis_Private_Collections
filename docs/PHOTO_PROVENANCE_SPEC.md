# Photo Provenance and Reference Image Specification

## Goal
Clearly distinguish the owner's actual item photographs from images used only for identification or research.

## Coin photos
- Obverse: owner's photo when available
- Reverse: owner's photo when available
- Edge: optional owner's photo when relevant

## Paper Money photos
- Face/front: owner's photo when available
- Reverse/back: owner's photo when available

## Reference images
If an image is not a photograph of the owner's actual item, it must be visibly labeled with a small, unobtrusive **Reference Image** or **Reference Photo** indicator.

Reference images should include source/credit information when available. They must never be presented in a way that could make the viewer think the image depicts the owner's specific item.

## Export behavior
Buyer-facing reports should clearly distinguish owner's photographs from reference images. Reference images should not replace the owner's photos when the owner has supplied actual photos.
