# Backup and Restore Safety

## Goal
Protect the collection while making backup and restore understandable and safe.

## Backup
The owner should be able to create a saved copy of collection data before major changes.

## Restore wording
Use simple wording next to Restore, such as "Get a saved collection back." This makes clear that Restore means recovering a saved collection, not resetting the app.

## Confirmation
Before restoring, show a short confirmation explaining that the selected saved collection will replace the current collection data. Provide Cancel and Confirm choices.

## No accidental reset
Restore must not be presented as a general Settings reset or a way to turn optional sections on/off.

## Optional sections
Restoring collection data must preserve the saved information associated with optional sections. Hidden sections can be shown again later through Settings.

## Future-proofing
Backup data should retain stable record IDs and enough structure to restore records, photos, documents, quantities, statuses, and optional-section data safely.
