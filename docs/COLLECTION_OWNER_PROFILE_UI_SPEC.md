# Collection Owner Profile UI

## Placement
Use a small avatar/name area in the catalog header or navigation area. It should remain secondary to the collection itself.

## Interaction
- Tap the avatar/name to open Profile settings.
- Choose a photo from the device or use a neutral default avatar.
- Enter or change the display name/collection name.
- Remove the photo to return to the default avatar.

## Export controls
Export screens should include an explicit optional control for including the owner name/avatar. Default: excluded.

## Design principle
The profile is an ownership/identity feature, not a social feed, follower system, or public profile unless a future feature explicitly adds those capabilities.
