# Record Archiving

## Goal
Keep old or inactive collection records out of the everyday catalog without deleting them.

## Archive action
A collectible may be marked Archived when the owner no longer wants it in the active collection view.

## No deletion
Archiving must not delete the record, photographs, certificates, notes, provenance, or history.

## Search
Archived records should be excluded from the normal active list by default but remain searchable through an Archive filter.

## Restore
An archived record can be returned to the active collection with a simple Restore/Unarchive action. This is separate from restoring a backup.

## Quantity
If a grouped record is archived, its quantity remains intact.

## Dashboard
Active collection totals should not count archived records by default, while archive totals can be shown separately.

## Future-proofing
Archive status should be a record-level property so the feature can work across coins, paper money, and future collectible categories.
