# Collection Dashboard and Summaries

## Goal
Provide a quick overview of the collection without requiring the owner to search through individual records.

## Dashboard information
The main dashboard may show counts for:
- total physical pieces
- total catalog records
- coins
- paper money
- grouped quantities
- certified items
- items with COA = Yes
- items needing research
- items missing photographs

## Composition summaries
The dashboard should support summaries by composition, such as silver, copper, gold, and other recorded materials.

## Filters and drill-down
Every summary should be selectable so the owner can move from a count to the corresponding filtered records. For example, tapping Silver should show the silver items rather than merely displaying a number.

## Quantity awareness
Totals should count physical pieces using Quantity. A record with Quantity = 10 contributes ten pieces to the physical-piece total while remaining one catalog record.

## No valuation assumptions
Collection counts and composition summaries should not imply market value. Value information should remain a separate, clearly identified feature.

## Privacy
Dashboard information is private by default and should not be publicly exposed merely because the application has a web address.

## Future-proofing
New collectible categories, compositions, and summary metrics should be addable without redesigning the entire dashboard.
