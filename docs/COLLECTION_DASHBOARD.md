# Collection Dashboard

## Goal
Provide a simple overview without overwhelming the owner with details.

## Main totals
The dashboard may show useful high-level totals such as active item count, archived item count, and quantities where applicable.

## Composition summary
When composition data is available, the owner can quickly see counts by recorded composition, such as Silver or Copper.

## Unknown data
Unknown / Not Checked values remain separate from confirmed No and should not be silently counted as No.

## Optional sections
Dashboard cards or summaries for COA, History & Provenance, metal testing, or other optional sections should only appear when the related section is enabled or when the owner chooses to view it.

## Clean layout
The dashboard should prioritize a few useful numbers and simple navigation rather than displaying every field from every collectible.

## Future-proofing
Additional summary cards can be added later without changing the core collection records.
