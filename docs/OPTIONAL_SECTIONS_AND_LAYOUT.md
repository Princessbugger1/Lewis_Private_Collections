# Optional Sections and Clean Layout

## Goal
Keep the main collectible record clean and easy to use while allowing detailed information to be available when wanted.

## Optional sections
Sections that are not needed for every item should be independently toggleable, including History & Provenance and other future detail sections.

Turning a section off hides it from the normal record view and entry flow; it does not delete information already stored in that section.

## Main record
The primary identification information should remain visible without requiring optional sections to be enabled.

## Consistent behavior
Optional sections should use the same simple on/off pattern and should be easy to find in the record/settings controls.

## No data loss
Hiding an optional section must never erase its saved information.

## Future-proofing
New optional sections can be added later without making the main record more cluttered.
