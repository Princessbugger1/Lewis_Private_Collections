# Quick Entry and Editing

## Goal
Make adding and updating a collectible fast on a phone without sacrificing useful detail.

## Main entry screen
Show only the most important fields by default. Optional sections remain available through their own controls.

## Simple controls
Use clear labels, large touch targets, and compact controls appropriate for a phone screen.

## Three-state fields
Applicable yes/no fields use the standard three-state control:
- ❓ Unknown / Not Checked
- ✅ Yes
- ❌ No

One tap advances to the next state and a further tap cycles back to Unknown / Not Checked.

## Quantity
Quantity is a small, easy-to-edit field and defaults to 1 where applicable.

## Save behavior
Saving should be clear and should not require the owner to complete optional fields.

## Editing
An existing record should be easy to edit without creating a duplicate record by accident. The stable record ID remains unchanged when ordinary fields are edited.

## No hidden assumptions
The application should not turn a blank optional field into No, and should not infer Yes merely because an attachment or related record exists.

## Future-proofing
The entry layout should allow additional optional sections without making the main screen crowded.
