# Main List Navigation Specification

## Goal
Keep the main catalog screen uncluttered while making large collections fast to browse.

## Organization
- Primary organization follows familiar numismatic ordering such as denomination/type and year where appropriate.
- Inventory/organization number remains available as a stable reference but should not dominate the visual layout.
- The user may sort/filter without changing the underlying record order.

## Navigation
- Search is available from the main list.
- Filters can narrow by year, denomination, country/mint, grade, group, and other available fields.
- A compact result count shows how many records match.
- Tapping a record opens the complete Coin Detail View.
- Returning from details preserves the previous search, filter, sort, and scroll position when practical.

## Empty states
If no records match a filter, show a plain-language message and an obvious way to clear filters.

## Accessibility
Controls should have readable labels and sufficient tap targets for phone use. Avoid requiring precise taps on tiny icons.
