# Export Privacy Checklist

Before creating a shareable export, the catalog should clearly show what information will leave the app.

## Default sale-list exclusions
- Purchase cost
- Storage/location details
- Private notes
- Internal organizational details that are not needed by the recipient

## Default sale-list inclusions
- Inventory number when useful
- Coin identification
- Year, denomination, country/mint, and variety when present
- Grade/condition
- Selected photos
- Asking price when entered for the sale
- Public-facing description/notes

## Review
Show a concise preview/count of records and included fields before generating the file. The user can change the selection before finalizing.
