# Coin Image Viewer UX

## Purpose
Give collectors a simple way to inspect a saved coin without changing its stored image.

## Opening
- Tapping the coin's main thumbnail opens the larger image viewer.
- Hovering is not required to open the viewer; hover may be used only as a subtle desktop visual cue if appropriate.
- The existing tap-to-open behavior remains the primary interaction.

## Inspection
- Pinch to zoom on touch devices.
- Mouse-wheel/trackpad zoom on computers.
- Drag/pan while zoomed.
- Provide a clear close/back action.
- Zooming and viewing never create additional image files.

## Relationship to editing
The viewer is for inspection only. Editing the coin record remains on the coin's edit page, as already designed. Crop/rotate controls belong to the photo-editing step and should not appear in the normal viewing experience unless the user explicitly enters edit mode.

## Simplicity
Do not add unnecessary viewer controls. The collector should be able to tap the thumbnail, inspect the coin, and return to the record immediately.
