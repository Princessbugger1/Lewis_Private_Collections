# Scan & Identify Specification

## Goal
Provide a simple workflow for photographing both sides of a coin and using authorized research/identification capabilities to suggest possible matches, while keeping the collector in control.

## Workflow
1. User taps Scan Coin.
2. Capture the obverse/front image.
3. Capture the reverse/back image.
4. User taps Identify/Research.
5. The system presents one or more possible identifications for review.
6. User can confirm a match, choose another possibility, reject all matches, or enter information manually.
7. After confirmation, the selected information can prefill the catalog item's fields and the two scan images can become the initial obverse/reverse photos.

## Identification language
- Never display a confidence rating such as High, Medium, or Low.
- Never present image/research identification as authentication or certainty.
- Use neutral wording such as "Possible identification".
- When multiple matches exist, present them as possible matches for user review.
- Provide a compact information icon for the explanation that identification is an estimate and should be verified.
- On first use, show a short explanation and offer "Don't show this reminder again."
- If dismissed, keep the explanation available under Settings > Research & Identification and allow the reminder to be turned back on.

## Safety and accuracy
- Identification is a suggestion; the collector makes the final decision.
- Do not silently create or overwrite a catalog record from an identification result.
- User must review and confirm before saving.
- The system should not claim authenticity, grade, variety, or attribution as fact solely from images or internet research.
- External research must follow the provider's permitted access and use rules.

## Usability
- Keep the identification screen uncluttered.
- Use clear front/reverse camera guidance.
- If the device supports a camera, allow capture on phones, tablets, laptops, and desktops.
- If no camera is available, allow image upload where appropriate.
