# Avatar Source Options

The collection owner profile may use any of these optional avatar sources:

- Personal profile photo
- Neutral default avatar
- A favorite coin image from the user's own catalog

## Favorite coin avatar
The user can choose an existing catalog coin and use its saved photo as the profile avatar. The original coin record remains unchanged; changing or removing the avatar does not affect the coin.

## Privacy and exports
The avatar source is a profile preference. A coin image used as an avatar should not automatically add that coin's private catalog information to an export. Export inclusion remains an explicit choice.
