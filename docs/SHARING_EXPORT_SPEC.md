# Sharing and Export Specification

## Goal
Let the owner share selected records without handing over the editable catalog.

## Export options
- Export selected records
- Export all records in a chosen category
- Export the entire collection
- Export a clean read-only report suitable for sending to a buyer

## Formats
Support a simple shareable report (PDF) and a data export (CSV) for the user's own use.

## Privacy
The user chooses which fields are included. Sensitive/private fields such as serial numbers should be excluded by default from buyer-facing exports.

## Multiple selection
The owner can select many records at once and export them together. The export is a separate copy; editing it does not modify the catalog.

## Clarity
The export should be clean and uncluttered, with photos and important identification/value information prioritized over internal organizational fields.
