# Search and Filter Specification

## Goal
Find coins quickly without requiring the owner to remember exact terminology.

## Search
Provide one prominent search bar that can search across the collection. Examples include:
- City or mint name such as San Francisco
- Year
- Denomination
- Coin type
- Country
- Catalog number
- Notes and identifying text

A search for "San Francisco" should return matching records regardless of denomination or year.

## Mint filters
Provide easy selectable mint options rather than requiring users to type a mint letter. Examples include:
- Philadelphia (P)
- Denver (D)
- San Francisco (S)
- West Point (W)
- New Orleans (O)

Mint filtering applies to all applicable coin types, not only modern quarters.

## Filters
Allow optional filters for category, date/year, denomination, mint, country, grade, certification, and other relevant fields.

## UX
- Search and filters should be quick to clear.
- Combining search text with filters should narrow results together.
- Do not crowd the main screen with every possible filter; put additional filters behind a simple Filter control.
