# Archive Retention Policy

## Rule
Archived coin records do not automatically expire. An archive is an organizational state, not a temporary holding period.

## Lifecycle
Active → Archive → Restore or Trash → Permanent Delete

## Retention
- Keep archived records until the user chooses to restore or delete them.
- Never silently purge archived coins because they have not been viewed recently.
- Archive retention is independent from photo-storage cleanup.
- Storage cleanup may remove local originals only through the verified backup/storage workflow and must not silently change an archived record into a deleted record.

## User controls
Provide clear Archive, Restore, Move to Trash, and Permanent Delete actions. Archived totals and reports should be clearly distinguished from active totals.

## Subscription considerations
If cloud storage is part of a subscription, the final product terms must explain what happens to archived cloud data if a subscription is canceled or expires. Local/user-controlled copies should remain governed by the user's own storage and backup choices.

## Recovery
Restoring an archived record should be reversible through normal workflows. Permanent deletion remains subject to the separate Trash/recovery policy.
