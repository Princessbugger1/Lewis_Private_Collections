# Release Readiness Checklist

## Product experience
- [ ] First-time setup works from start to finish with the main mascot.
- [ ] First test coin can be completed without hidden required steps.
- [ ] User can repeat the guided demonstration and then leave onboarding independently.
- [ ] Unfinished coin recovery is clear and safe.
- [ ] Cancel/delete behavior is explicit and protected against accidental loss.
- [ ] Back navigation does not create an unusable stack of duplicate screens.
- [ ] Search and filters work on structured fields and natural-language requests.
- [ ] Three-state fields correctly distinguish Unknown, Yes, and No.

## Data safety
- [ ] Autosave/draft behavior has been tested for interruptions and app closure.
- [ ] Local/export backup has been tested on small and large collections.
- [ ] Restore has been tested without accidental overwrite or duplication.
- [ ] Trash/permanent-delete warnings are clear.
- [ ] Any recovery process has documented verification requirements.

## Performance
- [ ] Large collections remain responsive.
- [ ] Image thumbnails are used appropriately.
- [ ] Full-size images are not unnecessarily loaded into list views.
- [ ] Search is indexed/debounced/virtualized as appropriate.
- [ ] Mascot screensaver remains within its animation budget.
- [ ] Decorative animation pauses when the app is backgrounded.
- [ ] Reduced-motion and animation-off settings work.
- [ ] Camera/research work does not unnecessarily block the main catalog UI.

## Accessibility
- [ ] Text remains readable at supported accessibility sizes.
- [ ] Tap targets are large enough.
- [ ] Important controls have accessible names/semantics.
- [ ] Color is not the sole indication of a field state.
- [ ] Mascots never cover essential information.
- [ ] Core workflows remain fully usable with animation disabled.

## Originality and third-party content
- [ ] Mascot artwork is original or properly licensed.
- [ ] UI artwork, icons, sounds, and animations are original or properly licensed.
- [ ] Product name and mascot names have been screened for trademark conflicts.
- [ ] External coin/reference services are used through permitted methods.
- [ ] Third-party trademarks are not presented as endorsements.
- [ ] Competitive originality review has been completed before launch.

## Commercial/legal gate
- [ ] Final Terms of Service reviewed by qualified counsel.
- [ ] Final Privacy Policy reviewed by qualified counsel.
- [ ] Subscription/refund/downgrade terms reviewed.
- [ ] Data/security and liability language reviewed.
- [ ] User-content and photo provisions reviewed.
- [ ] Account deletion/export rules reviewed.
- [ ] Support/recovery procedure reviewed.
- [ ] Children's/age-related requirements reviewed if applicable.
- [ ] Patent strategy explicitly accepted or declined after professional advice if desired.

## Store release
- [ ] App package/build is reproducible.
- [ ] App icon, screenshots, descriptions, and store copy are original and accurate.
- [ ] Privacy disclosures match the actual data practices.
- [ ] Subscription products and prices match the documented plan behavior.
- [ ] Production analytics/crash reporting has been reviewed for privacy and necessity.
- [ ] Final backup/export and account-deletion flows have been tested on real devices.
