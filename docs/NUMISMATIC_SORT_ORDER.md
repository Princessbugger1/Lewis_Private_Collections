# Numismatic Sort Order

The primary collection view should use familiar numismatic ordering while remaining flexible for different countries and coinage systems.

## Default ordering
1. Country / issuing authority
2. Denomination
3. Year
4. Mint mark
5. Variety or subtype when applicable
6. Grade / condition as a secondary detail

## User control
- The collector can change sorting when needed.
- Search and filters must not destroy or permanently reorder the stored records.
- Foreign and ancient coins may use the fields that make sense for their own conventions rather than being forced into U.S.-centric fields.

## Principle
The default should feel immediately familiar to a coin collector, while the digital catalog remains worldwide and adaptable.
