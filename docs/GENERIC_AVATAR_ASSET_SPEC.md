# Generic Avatar Asset Specification

Generic avatars are built into the catalog and require no external avatar service.

## Initial choices
- Neutral person/profile icon
- Coin-themed icon
- Numismatic/collector icon
- Optional additional neutral choices later

## Requirements
- Local/static assets bundled with the app
- No remote avatar downloads or third-party profile service
- Accessible labels for each choice
- User can return to the default avatar at any time
- Avatar selection remains independent from collection records

## Privacy
Built-in avatars contain no personal information and do not transmit user data.
