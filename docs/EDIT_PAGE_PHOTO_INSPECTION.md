# Edit Page Photo Inspection

## Main coin photo
On the coin edit page, tapping the main coin photo opens the same inspection behavior used for saved collection viewing.

## Behavior
- Tap to open the larger image.
- Pinch to zoom and drag on touch devices.
- Use mouse-wheel/trackpad zoom and drag on computers.
- Close the viewer to return to the edit page.
- Inspection does not modify the photo.
- Inspection does not create additional stored copies.

## Editing remains separate
Cropping and rotation are editing actions and are available only when the user explicitly enters the photo-editing step. Normal enlargement/inspection must not accidentally activate editing.

## Consistency
Use the same viewer interaction wherever the main coin photo is displayed so collectors do not have to learn different zoom behavior in different parts of the program.
