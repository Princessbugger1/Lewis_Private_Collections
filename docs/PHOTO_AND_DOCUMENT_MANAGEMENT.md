# Photo and Document Management

## Goal
Make photographs and certificate/document images easy to attach while keeping the catalog clean.

## Photos
Each collectible can have one or more photos. The primary photo should be easy to identify, and additional photos can be added when useful.

## Optional attachments
Certificate of Authenticity images and other supporting documents should live in their own optional attachment area rather than cluttering the main record.

## COA relationship
A COA can be marked using the standard three-state field: ❓ Unknown / Not Checked, ✅ Yes, or ❌ No. When COA = Yes, the optional COA details can include certificate issuer, certificate number, notes, and a photo.

## Photo status
Where applicable, photo completeness can use the same three-state control so Unknown / Not Checked is never treated as No.

## Organization
Attachments should remain linked to the stable collectible record ID so they survive ordinary editing, backup/restore, and record organization.

## Safety
Removing an attachment should require a deliberate action and should not delete the collectible record.

## Future-proofing
The attachment structure should allow additional document types later without changing the main record layout.
