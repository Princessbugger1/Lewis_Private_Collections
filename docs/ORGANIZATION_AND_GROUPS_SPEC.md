# Organization and Custom Groups Specification

## Goal
Let the owner organize records without forcing them into a rigid filing system.

## Default organization
Use the existing catalog organization (such as place/stock number plus year, denomination, mint, and type) without adding unnecessary fields to the main list.

## Custom groups
Allow the owner to create a group with any name, then add or move selected records into that group.

Examples:
- Coins to Sell
- Family Collection
- Favorites
- Needs Grading
- 2026 Auction

A record may belong to more than one custom group without being duplicated.

## UX
- Create a group from the Groups/Collections control.
- Name it anything the owner wants.
- Select multiple records and add them to the group.
- Moving a record between groups changes organization only; it never deletes or duplicates the underlying record.
- Groups should remain optional so the main catalog stays uncluttered.
