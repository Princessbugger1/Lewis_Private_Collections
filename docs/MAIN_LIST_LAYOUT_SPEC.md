# Main Collection List Layout

## Goal
Keep the collection list clean and fast to scan while preserving complete information in the full Coin Details view.

## Recommended row priority
1. Coin thumbnail/photo when available
2. Inventory # (compact identifier)
3. Year + denomination + country/mint information
4. Grade/condition when present
5. Optional compact status/group indicators only when enabled

## Details access
Tapping a row opens the complete Coin Details view. Users should never need to visit Settings merely to view stored information such as composition, expected weight, actual weight, or metal-test observations.

## Responsive behavior
- Mobile-first layout.
- Avoid horizontal scrolling for ordinary browsing.
- Secondary information can wrap or move below the primary identification line.
- Long country, variety, or notes text should not force the entire list to become wide.

## Settings
Settings determine which optional fields appear in the main list. They do not delete or hide those fields from the full record.

## Accessibility
Targets should be easy to tap, labels should be understandable without icons alone, and important actions should remain usable with larger text/display settings.
