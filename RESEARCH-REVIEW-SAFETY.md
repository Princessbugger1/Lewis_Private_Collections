# Research Review Safety

Before external research is connected, the review layer must remain explicit and reversible.

- Display each research suggestion separately from the saved catalog value.
- Show the provider/source and confidence when supplied.
- Allow **Accept**, **Reject**, or **Leave unchanged**.
- Accepting a suggestion may populate only the specific fields the user approves.
- Never overwrite an existing user value merely because research returned a different value.
- Never replace a user's normal edit with an automated result.
- Preserve original photos and notes when a result is rejected.
- Counterfeit research is a warning/suggestion, not image-only authentication or a definitive counterfeit determination.
- Research failures must leave the catalog unchanged.

## Future review record
When practical, keep a lightweight research timestamp/source record so the user can tell when information came from external research rather than from their own entry.
