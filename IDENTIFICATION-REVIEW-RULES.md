# Identification and Review Rules

Automatic identification is an assistant to the collector, never an unquestionable authority.

- Identification may use entered fields, selected photos, OCR, and explicitly requested external research.
- Proposed values must be visually distinguished from confirmed catalog values.
- A proposed identification should show its source/method when practical, such as manual entry, OCR, or external lookup.
- The user can Accept, Reject, or Edit a proposal using compact, clearly labeled controls.
- Accepting a proposal updates only the fields the user approves.
- Rejecting a proposal leaves confirmed values unchanged and records the decision when audit history is enabled.
- Conflicting sources should be presented for review instead of silently choosing one.
- Low-confidence or incomplete identification remains Needs Review.
- Every classification, series, country/issuer, denomination, year, mint, variety, grade, and certification field remains editable after identification.
- Identification must never change the stable record ID or create a duplicate record.
- Research results are evidence/suggestions and should not be represented as guaranteed authenticity or valuation.
- The UI must make clear when information came from an outside source.
