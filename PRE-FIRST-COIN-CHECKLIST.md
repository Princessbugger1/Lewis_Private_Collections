# Pre-First-Coin Checklist

Do not enter the full real collection until these working checks pass.

- [ ] Add one real coin and save it.
- [ ] Reopen the catalog and confirm the coin remains.
- [ ] Edit a field such as mint mark and save.
- [ ] Add/replace photos and confirm they remain attached.
- [ ] Verify the applicable three-state checks cycle correctly.
- [ ] Search, filter, and sort without changing the stored record.
- [ ] Hide and re-show optional categories without deleting records.
- [ ] Delete a test record and verify the intended recovery behavior.
- [ ] Create and restore a backup before bulk entry.
- [ ] Verify research suggestions are advisory and do not silently overwrite user-entered facts.
- [ ] Verify the authenticity/grading disclaimer is visible where research or images are presented.
- [ ] Confirm the current working files remain intact after the test.

## Release gate
Only after the checks above pass should the owner begin entering the larger real collection. If a check fails, fix and retest the affected workflow first.
