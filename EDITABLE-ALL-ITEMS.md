# Editable Classification Rule — All Collection Items

Every item entered into the catalog must remain editable after it is saved, including its classification/type. This is not limited to the currently known categories.

Examples include coins, banknotes/paper money, tokens, medals, commemoratives, counterfeits, ancient pieces, bullion, sets, exonumia, and any future category added to the catalog.

A user may change an item's classification later, save it, and continue using the same record. The change must not delete or reset photos, notes, provenance, certification details, research, values, or other unrelated fields.

The UI should expose the classification for editing wherever the item record can be edited. Hiding a category in Settings changes only visibility; it never makes the underlying records inaccessible or deletes them.
