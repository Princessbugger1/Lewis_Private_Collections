# Collection Views and Subtabs Rules

Collection navigation should organize records without turning categories into rigid, destructive silos.

- The main Coins area may provide useful subviews such as U.S. Coins, World Coins, Ancient Coins, Sets, and other applicable groupings.
- Specialized series or programs, such as America the Beautiful quarters, can appear as a subview or series when the data supports it.
- A subview is a filtered/grouped view of the same underlying records, never a second copy.
- The year, type, country/issuer, denomination, and series can all contribute to automatic grouping where appropriate.
- Users can still search for an item directly regardless of which subview normally displays it.
- A record can be moved between applicable groupings by editing its attributes; this must not create a duplicate.
- User-created subviews/series may be added as the collection grows.
- Empty subviews should not be created merely because a preset exists; navigation should remain clean.
- The interface should allow the user to switch between broad and specialized views without losing the ability to return to the complete collection.
