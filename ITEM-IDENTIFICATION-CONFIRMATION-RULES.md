# Item Identification Confirmation Rules

Automatic identification is assistive, not authoritative.

1. The catalog may suggest a series, type, country/issuer, or other metadata from entered fields.
2. Suggestions must be visibly distinguishable from user-confirmed values.
3. The user can accept, edit, reject, or leave a suggestion unresolved.
4. A suggestion must never silently overwrite a value the user deliberately entered.
5. Conflicting or incomplete data should produce an Unknown / Needs Review state rather than a confident guess.
6. Manual edits remain authoritative until the user changes them.
7. Identification changes must preserve the stable item record and all attached photos, notes, values, certification, provenance, and research.
8. For valuable or unusual items, the catalog should favor review/confirmation over aggressive automatic classification.
