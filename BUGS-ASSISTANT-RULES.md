# Bugs Assistant Rules

Bugs is a small, optional visual helper for the catalog. Bugs may guide the user without taking control of collection decisions.

- Bugs may appear quietly as a small mascot in the normal interface.
- Bugs should not constantly speak, animate, interrupt, or demand attention.
- Bugs may point toward a field or control when the user needs help completing a task.
- Bugs may present concise suggestions such as identification proposals, missing-field reminders, or password-help prompts.
- Suggestions must use clear actions such as Accept, Edit, Research, Dismiss, or Forgot Password when applicable.
- Bugs must never silently change a collection record.
- The user remains the final authority over identification and collection data.
- Bugs tips can be dismissed and should not repeatedly nag about the same resolved issue.
- Users should be able to disable Bugs tips while keeping the mascot visible if desired.
- Important security, deletion, authentication, and data-loss warnings must remain clear even if Bugs is disabled.
- Bugs artwork and personality should remain visually friendly and small enough not to interfere with catalog controls.

## Idle screensaver

- After a configurable period of inactivity, Bugs' small bug friends may crawl or float around the screen as a quiet screensaver.
- The idle animation must not edit data, trigger actions, obscure important information, or require interaction.
- Any normal tap or user interaction immediately ends the idle animation and returns to the active catalog.
- The main Bugs mascot remains in its normal location while the bug friends scatter away.
- The idle feature should have an on/off setting and should not play sound by default.
- The idle animation must respect battery/performance considerations on phones.

## Design direction

- Bugs is currently envisioned as a small golden inchworm or similar distinctive collectible-themed bug.
- The exact artwork is intentionally not finalized yet.
- Optional props such as a pointer or magnifying glass may be used to communicate what Bugs is helping with.
