Lewis Private Collections — My Coin Book

This repository contains the working phone-friendly coin catalog prototype.

Current prototype:
- Add and delete coin records.
- Simple tap-to-cycle three-state fields for applicable yes/no questions:
  ❓ Unknown / Not Checked → ✅ Yes → ❌ No → ❓ Unknown / Not Checked
- Fields include COA, OGP, Original box, Sigma tested, Photos complete, and Variety checked.
- Records are currently stored locally in the browser on the device.
- GitHub Pages can host the catalog as a simple web app.

Next development stages:
- Build out the full catalog data model and screens.
- Add coin photos and photo management.
- Add searching, sorting, filtering, and collection organization.
- Add the remaining fields and workflows from the Lewis Private Collections requirements.
- Add a reliable backup/sync strategy before treating GitHub as the live data store.
